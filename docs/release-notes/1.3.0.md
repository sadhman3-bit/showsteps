ShowSteps 1.3.0 adds **brand kits**, so every exported file looks like your organisation's. It also brings a round of **security** fixes, listed below.

## What's new

- **Brand kits.** **Branding** in the library's sidebar sets how every PDF, Word file, web page, embed card and Markdown file looks:
  - colours, and fonts, including your own TTF or OTF file;
  - logos for light and dark backgrounds;
  - the cover: a band with the trail pattern, a plain colour, your picture, or no band. Show, hide and reorder its parts;
  - a page header and footer with the title, company, page numbers, date and author;
  - a notice on every page, A4 or US Letter, step number style and picture borders.
- **ShowSteps's marks are optional.** A kit can drop each of them: the trail pattern, the Guide Me and Run for me links, the "Agent-readable procedure" line, the procedure inside PDF and Word files, and "ShowSteps" as the file's creator (your company name instead).
- **One look for everything, with exceptions.** Choose a default kit for all guides. In the editor, **Branding** picks another kit for one guide and keeps changes for that guide only (**Reset to the kit** removes them). The Share dialog can use another kit for one export.
- **Preview** a kit on a sample guide as you change it, or open a PDF made with it.
- **Share a kit** as a `.showsteps-brand` file, or put one in a team folder's `.brand` folder so everyone sees it as a team kit.

Without a kit, exports look exactly as they did in 1.2.

## Security

- **Shared guide files carry blurs burned in.** A `.showsteps` file you export or share holds the blurred and cropped pictures only. It leaves out what was under a blur, the page text kept for Secure Blur, pictures from before your edits, and who last edited the guide. **Back up (includes hidden details)** in the library's ⋯ menu keeps a full copy for yourself, after a warning.
- **Guides from others ask before they act.** An imported guide, or one someone else saved last in a team folder, shows what it does before Run for me's first run: its sites, the values it types, the files it moves and where it stops. It starts only after you tick **I've checked this guide**.
  - Steps whose button can't be undone ask again, whatever the file says.
  - Run for me checks the name of the button actually on the page before clicking.
  - Such a guide can't be scheduled until you choose **Trust this guide**.
- **Run for me attaches only files from the step's own site.** A file from another site is never attached, and the run stops and says which sites. If a download is passed on to another address, that address is fetched without your cookies.
- **Passwords stay out, even when shown.** A field that was secret stays secret for the whole recording, even after **Show password**. Fields named PIN, CVV, BSB, account number and similar count as secret too. A secret field with a value is blurred in the screenshot. Steps that came from the page's own scripts are marked in the editor, for you to keep or delete.
- **Only your clicks press ShowSteps's buttons.** A page's scripts can no longer press Confirm, Skip, Stop or Finish.
- **The desktop connection checks it's really ShowSteps.** The extension relays only to ShowSteps itself, running as your Windows account, so another account on the same PC can't stand in for it.
  - Desktop windows can't be navigated away.
  - Exports never overwrite a file of the same name.
- **Safer files and updates.** Guide files that unpack to too much, or hold anything but a guide and its pictures, are refused before unpacking. The Agent Pack's replay script and instructions can't be turned into code by step names. Electron, zod and DOMPurify are updated.

## Updating

- **Extension (Chrome Web Store):** updates by itself, with no permission prompt (no new permissions).
- **Extension (unpacked):** unzip `showsteps-extension-1.3.0.zip` over your existing folder, then click **↻** on ShowSteps in `chrome://extensions`. Your guides are kept.
- **Desktop app:** run `ShowSteps-Setup-1.3.0.exe` over the old version. Your library and settings are kept.
  - **Update the extension and the desktop app together.** The connection now checks it's really ShowSteps, so an older desktop app shows as offline to extension 1.3, and the reverse.
- **Team folders:**
  - Guides others saved last ask once before Run for me, until you choose **Trust this guide**.
  - A guide saved in 1.2 by someone else keeps its brand settings, but 1.2 ignores the kit.

## Privacy

The privacy policy has a new section, **Brand kits**: kits stay on this device, or in the team folder's `.brand` folder; brand files hold no guide content; and pictures you add are redrawn, which drops their metadata. It also has **Guides from other people**. **Never stored**, **Files a run attaches** and **When data leaves your computer** are updated for the changes above.

## Checksums

`SHA256SUMS.txt` lists the SHA-256 checksum of each file. See the [installation guide](https://github.com/sadhman3-bit/showsteps/blob/main/docs/INSTALL.md) for how to check them.
