ShowSteps 1.1.0 adds **scheduled runs**: Run for me can run a guide on its own at the times you set.

## What's new

- **Schedule a guide.** Open a guide, then **⋯ → Schedule…** (or **Schedule…** on its library card). Run it every day, on weekdays, on chosen days, on a day of the month or on a business day of the month, at a set time, skipping dates such as public holidays.
- **Values for each run.** Answer in advance what Run for me would ask for. Dates can be placeholders filled in when each run starts, such as `{today}`, `{last_month_end}` or `{last_business_day}`.
- **Safe when nobody's watching.** A scheduled run opens its own Chrome window without taking focus. It pauses and tells you when it reaches a confirm step, a step only you can do, a sign-in page or a step it can't find, and waits for you. Confirm steps can be pre-approved for a schedule; any change to the guide's steps cancels those approvals.
- **Sign-in pages, in every Run for me.** When a site's session has ended and it sends you to sign in, Run for me stops with "Sign in, then press Continue". It never types passwords. A recorded one-click sign-in (an account tile, "Sign in with Microsoft") replays like any other click.
- **Run log.** The new **Schedules** page shows each schedule's next run and last outcome, with **Run now**, **Edit**, **Delete** and an on/off switch, and a history of the last 20 runs with the values typed and a picture after each step.
- **Notifications** (optional) when a run finishes, needs you, or is due for a guide with Windows-app steps. Without them, `!` on the toolbar icon shows when a run stopped.
- **Desktop app: Start with Windows**, and Chrome opens for a due run if it's closed.

What schedules can't do: run while the computer is asleep or off, or on a locked screen; do Windows-app steps on their own; or move between computers.

## Updating

- **Extension (Chrome Web Store):** updates by itself, with no new permission prompt. The new `alarms` permission shows no warning, and notifications are asked for only when you save a schedule.
- **Extension (unpacked):** unzip `showsteps-extension-1.1.0.zip` over your existing folder, then click **↻** on ShowSteps in `chrome://extensions`. Your guides are kept.
- **Desktop app:** run `ShowSteps-Setup-1.1.0.exe` over the old version (no need to uninstall). Your library and settings are kept. Desktop app 1.0 keeps working with extension 1.1, and the other way round; opening Chrome for runs needs both at 1.1.

## Privacy

The privacy policy has a new **Scheduled runs** section. Schedules, run logs and their screenshots stay in the extension's own storage on your computer, and are never synced or sent anywhere. Notifications are shown by Chrome on your computer and never contain typed values. The desktop app learns only when the next run is due. The policy now also states that ShowSteps's use of data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.
