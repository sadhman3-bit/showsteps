ShowSteps 1.2.0 lets Run for me **attach a file it downloaded**, puts **Guide Me and Run for me** wherever guides are listed, and adds **Guide Me and Run for me links** to exported files.

## What's new

- **Attach the file a run downloaded.** In the editor, an upload step has a new **File** setting: **Choose it yourself** (as before), **The file this run downloaded last**, or **The file downloaded in step N**. Run for me then puts that file into the upload field without opening a picker, for example a report downloaded in one step and attached to an email in a later one. Scheduled runs do it too, and their history says which file was attached ("Attached report.pdf (240 KB), downloaded in step 4").
- **Download access** (optional). The best results need Chrome's download access, asked only when you choose a downloaded file for an upload step. Without it, ShowSteps can attach files from simple download links and files the page builds itself.
- **Desktop app 1.2** reads the file Chrome saved, so downloads made by a form (an **Export** button that posts) can be attached too.
- **Guide Me and Run for me everywhere:** on each library card (and its ⋯ menu), in the editor's top bar, and in the side panel's Recent guides and Guides for this site. Run for me opens its dialog first (values, speed, step by step).
- **Links in exported files.** PDF, Word, web page, embed card, Copy HTML and Markdown exports have "Open in ShowSteps: Guide Me · Run for me" under the title. A link opens the guide's first page; in Chrome with ShowSteps and the guide in its library, a small ShowSteps window offers to start. Turn the links off in the Share dialog.
- **Agent Pack:** an upload step that uses a downloaded file says so in the instructions and the procedure, and the Playwright replay saves the run's download and uploads it.

What attaching can't do: upload areas that only take drag and drop; Outlook for Windows and other Windows apps; Chrome's "Ask where to save each file" setting (the download waits for you, so a scheduled run stops); downloads Chrome blocks as unsafe; files over 25 MB. In those cases Run for me stops at the upload step and says which file to choose from your Downloads folder.

## Updating

- **Extension (Chrome Web Store):** updates by itself, with no permission prompt. The new `downloads` permission is optional and asked for only when you use it.
- **Extension (unpacked):** unzip `showsteps-extension-1.2.0.zip` over your existing folder, then click **↻** on ShowSteps in `chrome://extensions`. Your guides are kept.
- **Desktop app:** run `ShowSteps-Setup-1.2.0.exe` over the old version (no need to uninstall). Your library and settings are kept. Desktop apps 1.0 and 1.1 keep working with extension 1.2; only attaching form downloads needs desktop app 1.2.
- **Team folders:** a guide edited in 1.2 and saved again by someone still on 1.1 loses its upload steps' **File** setting (those steps go back to **Choose it yourself**). Update everyone who shares a folder.

## Privacy

The privacy policy has two new sections. **Files a run attaches:** a copy of a file the run's own click downloaded is kept in the extension's storage for that run only (at most 25 MB a file, 50 MB a run) and deleted when the run ends; it is never written anywhere else or put into logs, notifications or exports. **Links in exported files:** the guide's ID and version go after a `#`, which browsers never send to the website, and nothing starts until you press Start.

## Checksums

`SHA256SUMS.txt` lists the SHA-256 checksum of each file. See the [installation guide](https://github.com/sadhman3-bit/showsteps/blob/main/docs/INSTALL.md) for how to check them.
