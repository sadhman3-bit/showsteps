ShowSteps: update the Chrome Web Store item to 1.1.0

About 10 minutes. Fields that changed have a Copy button below.

  1. Open the developer dashboard, chrome.google.com/webstore/devconsole, then the ShowSteps item (ID hlkihjibgiehjcaemfhfnfcjphgkcnoa).
  2. Package tab: Upload new package, and choose dist/showsteps-extension-1.1.0-chrome-web-store.zip.
  3. Store listing tab: paste the new Description (below) and add screenshot docs/webstore/images/4-schedules.png.
  4. Privacy practices tab: add the alarms and notifications justifications (below) and check that the data usage ticks are still Website content and User activity with all three statements. The privacy policy URL stays the same; the updated policy is live on main.
  5. Submit for review. To choose when it goes live, untick automatic publishing in the confirmation dialog; after approval you have 30 days to press Publish.

Description
Show a process once, and ShowSteps writes the how-to guide for you.

Click Start, do the task as usual, then click Finish. Every click, entry and choice becomes a step with a written instruction and a screenshot that highlights what you clicked. Steps appear in the side panel as you go, and you can delete any of them before you finish.

PRIVATE BY DESIGN
• Everything stays on your computer. No account, no cloud, no tracking.
• Values typed into password, one-time-code and payment-card fields are never stored.
• Secure Blur helps you find emails, phone numbers, and card, bank and tax numbers in your screenshots so you can blur them before sharing.

EDIT AND SHARE
• Reorder steps, add sections, tips and warnings, crop and annotate screenshots.
• Export to PDF, Word, Markdown or HTML, or copy into a document or wiki.
• Version history: go back to any earlier version.

GUIDE PEOPLE THROUGH IT
• Guide Me shows each step on the real page, one at a time.
• Run for me does the steps for you, and stops at passwords, at steps you mark for confirmation and whenever something unexpected happens.
• Scheduled runs: Run for me runs a guide at the times you set (daily, weekdays, chosen days or a day of the month) in its own window, pauses and tells you when it needs you, and keeps a log of each run with a screenshot per step.
• Pin guides and notes to the pages where they are needed.

FOR AUTOMATION
• Each guide also holds a precise, machine-readable procedure that automation tools and AI agents can follow, with a ready-made Playwright test.

Free for personal and non-commercial use (PolyForm Noncommercial License 1.0.0); the source code is available. ShowSteps is an independent project and is not affiliated with Google or with any other guide or documentation product.

Privacy

Single purpose
ShowSteps records a process the user performs in the browser and turns it into a step-by-step guide that people can read, follow on the page, or have performed for them.
Justification: sidePanel
The side panel is ShowSteps's main control: start and finish a recording, see the steps as they are recorded, and follow guides.
Justification: storage
Saves the user's settings, page notes, schedules and the state of a recording in progress, on this device.
Justification: unlimitedStorage
Guides and scheduled-run logs contain many screenshots; they are kept on this device, and they can exceed the default storage quota.
Justification: scripting
While the user records or follows a guide, ShowSteps adds its recording or guidance script to that page to see clicks and typing, or to highlight the next step. Nothing is added to other pages or at other times.
Justification: webNavigation
Notices when the recorded tab goes to a new page, so the page change becomes a step and its frames are mapped correctly.
Justification: Host permission <all_urls> (optional)
Requested only when the user first starts a recording or a walkthrough, or saves a schedule, because guides can be recorded on any website the user chooses. Used to take screenshots of the visible tab and to run the recording or guidance script on it.
Justification: nativeMessaging (optional)
Requested only if the user turns on the connection to the ShowSteps desktop app, to record Windows programs into the same guide. It talks only to that app, on the same computer.
Justification: alarms
Starts a guide's Run for me at the times the user sets in a schedule.
Justification: notifications (optional)
Tells the user when a scheduled run finishes, needs a confirmation or a sign-in. Requested only when the user creates a schedule.
